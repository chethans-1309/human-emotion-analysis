# Human Emotion Analysis Project

An AI-powered web application that detects human emotions, body gestures, head posture, and activities from uploaded images and live webcam feeds using Machine Learning, Deep Learning, and Computer Vision techniques.

---

## 📌 Project Overview

The Human Emotion Analysis Project is designed to analyze human behavior and emotional states through intelligent image and video processing. The system can process uploaded photos as well as real-time webcam streams to identify emotions, body gestures, head posture, and human activities.

The application supports multi-person detection, enabling analysis of multiple individuals simultaneously within a single frame. The project combines Artificial Intelligence, Human Activity Recognition, and Computer Vision to create an advanced smart monitoring and behavior analysis system.

## 📂 Project Modules

### 1. Emotion Detection

Detects emotions such as:

- Happy
- Sad
- Angry
- Neutral
- Fear
- Surprise

### 2. Body Gesture Detection

Analyzes human body movements and gestures using image processing techniques.

### 3. Head Posture Detection

Tracks head orientation and posture using facial landmark detection.

### 4. Activity Recognition

Recognizes activities such as:

- Standing
- Walking
- Sleeping
- Movement Detection

### 5. Live Webcam Detection

Performs real-time emotion and activity analysis using webcam video streams.

### 6. Multi-Person Detection

Detects and analyzes multiple individuals simultaneously in a single frame.

---

## ⚙️ System Workflow

1. User uploads an image or starts the webcam.
2. Input data is preprocessed.
3. AI models analyze the frame.
4. Emotions, posture, gestures, and activities are detected.
5. Results are displayed through the dashboard.

## ▶️ How to Run the Project

Follow these steps to run the Human Emotion Analysis Project on your system.

### 📌 Prerequisites

Make sure the following are installed:

- Python (compatible with the project's dependencies)
- VS Code or another IDE
- Webcam (for live detection)
- pip package manager

---

## ⚙️ Installation Steps

### 1. Clone the Repository

`git clone https://github.com/YOUR_USERNAME/human-emotion-analysis.git`

### 2. Navigate to Project Folder

`cd human-emotion-analysis`

### 3. Create Virtual Environment (Optional)

`python -m venv venv`

Activate environment:

**Windows**

`venv\Scripts\activate`

**Linux / Mac**

`source venv/bin/activate`

### 4. Install Required Packages

`pip install -r req_3_7_1.txt`

If the requirements file is incompatible, check the project's Python and dependency versions before installing packages individually.

---

## ▶️ Run the Application

`python app.py`

---

## 🌐 Open in Browser

After running, open:

`http://127.0.0.1:5000`
